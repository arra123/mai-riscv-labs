# Вычислительные системы, ПЗ1

Пущин Тимофей, М3О-121СВ-26, номер в списке 12.

Три программы на ассемблере RISC-V, запускал в [RARS](https://github.com/TheThirdOne/rars).

- `task_a.s` печатает 1, если ввели 12, иначе 0
- `task_b.s` печатает числа от min(x, 121) до max(x, 121) с шагом 12
- `task_c.s` читает числа в массив из 28 элементов, пока он не заполнится или не введут 0

Запуск: открыть файл в RARS, F3, потом F5. Или из консоли:

```
java -jar rars1_6.jar task_a.s
```
