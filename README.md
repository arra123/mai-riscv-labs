# Вычислительные системы: практическое занятие 02.10.2026

Пущин Тимофей Андреевич, группа М3О-121СВ-26, номер в списке группы: 12.

Программы на ассемблере RISC-V (RV32), проверены в симуляторе [RARS 1.6](https://github.com/TheThirdOne/rars).

| Файл | Задача |
|---|---|
| `task_a.s` | Читает целое x, печатает 1, если x равен номеру студента в списке группы (12), иначе 0 |
| `task_b.s` | Читает целое x, печатает значения от min(x, y) до max(x, y) с шагом h, где y = 121 (номер группы), h = 12 (номер студента) |
| `task_c.s` | Заполняет массив из 16 + n = 28 целых чисел со стандартного ввода; чтение заканчивается после 28 значений или после ввода 0 |

## Запуск

В RARS: открыть файл, Assemble (F3), Run (F5), ввод и вывод в окне Run I/O.

Из командной строки:

```
java -jar rars1_6.jar nc task_a.s
```

## Примеры

| Программа | Ввод | Вывод |
|---|---|---|
| `task_a.s` | `12` | `1` |
| `task_a.s` | `5` | `0` |
| `task_b.s` | `100` | `100 112` (каждое с новой строки) |
| `task_b.s` | `150` | `121 133 145` |
| `task_b.s` | `-5` | `-5 7 19 31 43 55 67 79 91 103 115` |
| `task_c.s` | `5 7 -3 0` | `3`, затем `5 7 -3` |
| `task_c.s` | числа от 1 до 40 | `28`, затем числа от 1 до 28 |

В `task_c.s` ноль служит признаком конца ввода и в массив не записывается. После чтения программа для проверки печатает число считанных элементов и сам массив.
